# Wattly
Nowoczesna aplikacja mobilna do monitorowania zużycia energii elektrycznej, analizowania kosztów i prognozowania rachunków. Umożliwia rejestrowanie odczytów licznika, konfigurację operatora i taryfy energetycznej, automatyczne przeliczanie kosztów oraz analizę zużycia za pomocą wykresów i statystyk.
